# Безопасность

## Что смотрит в интернет
Наружу через Tailscale Funnel открыт только веб-сервер мини-приложения «Синхросигнал» (`SyncHandler` в `bot.py`, порт 8790 внутри Docker):
- `GET /` — статичная страница, без данных;
- `GET /time` — время сервера, для сверки часов;
- `GET|HEAD /feed.xml`, `/media/<файл>` — RSS-фид подкаста и его аудио/обложки (только если задан `FEED_URL`). Это публичные данные по определению; отдаются только файлы из `DATA/feed` (`feed.xml` и `media/` с именами по белому списку `feed.NAME_RE`, без `/` и `..`), только чтение, докачка по `Range`, свой лимит 300 запросов за 10 с с адреса;
- `POST /api` — только с действующей подписью Telegram WebApp `initData` (HMAC-SHA256 от токена бота, не старше часа) или с токеном сессии, который бот выдал по такой подписи (`uid.срок.HMAC`, ключ выводится из токена бота, 12 ч; ID и срок подделать нельзя), и только от ведущих из `PEOPLE`. Остальным — 403. Темы (текст ведущих) отдаются только так же.

Защита: тело запроса не больше 8 КБ и читается только после проверки длины; таймаут соединения 10 с; не больше 32 одновременных соединений и 60 запросов за 10 с с одного адреса (429). Всё остальное (Telegram Bot API, файлы, ключи) снаружи недоступно: compose не публикует портов.

## Секреты
Ключи и токены лежат в `secrets/` (права 600), значения установки — в `.env`; оба в `.gitignore` и `.dockerignore`. Токен бота вырезается из текстов ошибок, чтобы не попасть в логи и сообщения.

## Входящие файлы
Дорожки присылают только ведущие из `PEOPLE` (чужим бот отвечает их Telegram ID, не чаще раза в час, содержимое сообщений не логирует). Ограничения: файлы до ~2 ГБ (Google Drive — с проверкой размера и общим временем загрузки), архивы — оглавление проверяется до распаковки (не больше 2000 файлов и ~4 ГБ), символические ссылки внутри игнорируются, права и владельцы из архива не применяются. Внешние программы (ffmpeg, bsdtar) вызываются со списком аргументов, без shell.

## Контейнеры
Бот работает не от root: uid 101 (тот же пользователь, что у локального Bot API — так он читает его файлы) с группой хоста `HOST_GID`; `cap_drop: ALL`, `no-new-privileges`, новые файлы — без доступа «всем» (umask 007). Узел Tailscale — в userspace-режиме, без `NET_ADMIN` и `/dev/net/tun`. Образы закреплены по версии или digest.

## Сторонние сервисы
Записи выпусков отправляются в AssemblyAI (расшифровка), расшифровка — в OpenRouter (LLM для начала, конца, глав и описания). Учитывайте это, если записи конфиденциальны.
